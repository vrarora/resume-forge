# LinkedIn Copy

Write `linkedin.md` with copy-paste blocks that match the main variant. LinkedIn has one profile, so match it to the variant the person cares about most.

## Sections

| Section | Limit | Guidance |
|---|---|---|
| Headline | 220 chars | Real title at company, then domain and spike, then one proof number, then "Ex-" notable employers. Recruiters search on it. |
| About | 2,600 chars | 4–6 short first-person paragraphs. Open with what they do in one plain sentence, then their biggest results, how they work, earlier roles in one paragraph, and a portfolio link. |
| Experience | 2,000 per role | Paste the ATS bullets, starting each with "• ". Use one entry for each title under a promotion. |
| Featured | — | Portfolio first, then 2–3 case studies or posts that show judgment. Drop casual posts. |
| Top skills | 5 | Match the target role's ATS keywords. |
| Honors & awards | — | Plain-language names with periods. |
| Open to work | — | Recruiters only, unless they're openly between jobs. List the target titles and locations. |

## Rules

- **Never put a job-search line in About** ("looking for senior roles") while the person is employed, because their employer can read it. "Open to work: Recruiters only" signals the search privately.
- Apply the same writing rules as the resume: impact first, plain words, no confidential names.
- **About is the one place for a summary-like opening**, because LinkedIn readers scroll and resume readers scan.
- **Only edit the live profile with the person's explicit go-ahead**, because changes publish immediately. The default is to hand over the copy so they paste it themselves.
